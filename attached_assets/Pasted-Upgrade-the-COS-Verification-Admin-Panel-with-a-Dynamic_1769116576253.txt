Upgrade the COS Verification Admin Panel with a "Dynamic AI Knowledge Engine."

### 1. Database & Schema Update (shared/schema.ts)
- Modify 'trusted_patterns' table: Add a text column 'ai_instructions' and 'last_updated' timestamp.
- Create a 'global_ai_rules' table: (id, category, rule_text, priority) for instructions that apply to ALL documents regardless of the specific pattern.

### 2. "Smart Upload" UI (client/src/pages/Admin.tsx)
- In the "Upload Pattern" section, add a rich-text or expanded Textarea labeled "Forensic Instructions for AI."
- Feature: When an admin uploads a new Genuine COS, the system should pre-extract its metadata and show it to the admin, allowing them to add specific notes (e.g., "This specific department always uses 'Microsoft Word 365' as the producer").
- Add a "Global Knowledge" settings tab where the admin can write general rules for the AI (e.g., "Always flag any document where the ModDate is on a Sunday as suspicious").

### 3. AI Analysis Pipeline (server/services/pdfAnalyzer.ts)
- Update the LLM reasoning endpoint:
  1. Fetch all 'Global AI Rules'.
  2. Fetch the 'AI Instructions' associated with the most likely pattern match.
  3. Construct a "Knowledge Context" block: 
     "<knowledge_base> {global_rules} \n {pattern_specific_instructions} </knowledge_base>"
  4. Inject this into the LLM's System Prompt: "Analyze this COS document based on the provided metadata AND the specific forensic knowledge base provided below."

### 4. Logic & Future-Proofing
- Every time a document is scanned, the AI must explicitly state in its 'reasoning' if it followed a specific Admin Instruction (e.g., "Flagged per Admin Rule #4 regarding Sunday modifications").
- Implement a "Reinforcement" button in the Logs: An admin can click "Teach AI" on a Fake COS, adding that specific forgery's marker to the global knowledge base instantly.

### 5. Performance Boosts
- Use TanStack Query 'mutation' to optimistically update the UI when a new pattern/instruction is added.
- Ensure the PDF extraction happens in a non-blocking background task.
