# Quarantine — Confirmed Fakes (EMPTY BY DESIGN)

This directory stays empty until a case arrives with ALL of:

- source case reference + handler identity,
- collection method + date,
- ground-truth basis (what was altered, how confirmed),
- independent second review (name + date),
- SHA-256 + immutable storage reference.

Until then: NO files, NO training, NO exceptions.

When populated, quarantined files are used as **held-out validation only**.
Promotion to training requires a separate written provenance review.
