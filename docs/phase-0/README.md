## Approval Standards

A sign-off is valid only if recorded in one of these systems:

1. GitHub PR approval on the artifact change
2. GitHub issue comment with this format: APPROVED by Name on YYYY-MM-DD

Verbal approvals and chat-only approvals are not valid sign-off records.
